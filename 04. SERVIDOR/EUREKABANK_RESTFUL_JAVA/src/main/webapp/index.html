EURECABANK REST

API RESTful en JSON. Base: /EUREKABANK_RESTFUL_JAVA/api. Las rutas protegidas exigen Authorization: Bearer <token>.

  • POST /api/auth/login
  • POST /api/auth/logout
  • GET /api/clientes/{cedula}/cuentas
  • GET /api/cuentas/{cuenta}
  • GET /api/cuentas/{cuenta}/movimientos
  • POST /api/cuentas/{cuenta}/depositos
  • POST /api/cuentas/{cuenta}/retiros
  • POST /api/transferencias
  • GET /api/cuentas/{cuenta}/costos
